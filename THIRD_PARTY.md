# Third-Party Components

This repository may use third-party software, libraries, Blender add-ons, tools, or reference material during development.

## Rules

1. Preserve the original copyright notice and license of every third-party component.
2. Do not assume the repository's `GPL-3.0-or-later` code policy overrides a component's own license.
3. When modifying GPL-covered third-party code, keep the original license notice and clearly mark local modifications where practical.
4. Do not commit proprietary binaries, installer payloads, or extracted game assets unless redistribution is explicitly permitted.
5. Prefer build/install instructions that obtain proprietary dependencies from their official source instead of mirroring them in this repository.

## Egosoft material

The following are intentionally not distributed from this repository unless Egosoft explicitly permits redistribution:

- original X4: Foundations game assets extracted from game data
- complete original game data containers
- Egosoft Blender Mod Tools installer packages
- `XUConverter.exe` / P1 Converter and other proprietary executable payloads
- other Egosoft-distributed files whose redistribution rights are not clearly granted

Use legally acquired copies of X4: Foundations and obtain official modding tools from Egosoft's official distribution channels.

## Adding a dependency

When a third-party component is intentionally committed, add an entry below with:

- component name
- upstream URL
- version / commit
- license
- local modifications, if any
